# DeepClause VC deck

Short investor deck: `DeepClause_VC_Deck.pptx`.

## Message

- **Headline:** "DeepClause — Turn an SOP into a harness."
- **Positioning:** robust, reliable, responsible, auditable.
- **Audience:** heavily regulated industries that need accountable agents.
- **Differentiator:** DML / neurosymbolic AI — deterministic Prolog workflow logic
  with bounded LLM/judgment leaves, not a free-form agent loop.

## Slide outline

1. Title — Turn an SOP into a harness.
2. Problem — traditional harnesses fail where accountability matters.
3. Differentiator — DML / neurosymbolic AI.
4. Product — `s2h`: SOP → validated harness → self-hosted runtime.
5. Trust — accountable agents by construction.
6. Example — refund desk (presentation diagram).
7. Example — refund desk (specification diagram).
8. Example — antenatal danger-sign triage (judgment leaves).
9. Business model — open-core, hosted, bespoke integration.
10. Ask — funding and milestones.

## Assets

`assets/` contains rendered diagrams from the example skills under
`examples/refund-desk/` and `examples/who-anc/`.

To regenerate the diagrams and deck:

```bash
npm install -g @mermaid-js/mermaid-cli pptxgenjs
npx puppeteer browsers install chrome

mmdc -p <(echo '{"args":["--no-sandbox","--disable-setuid-sandbox"]}') \
  -i examples/refund-desk/diagrams/refund-policy.presentation.mmd \
  -o docs/vc/assets/refund-policy.presentation.png -b white -w 1400
# ... repeat for each .mmd ...
```

The PPTX is generated by a small `pptxgenjs` script; regenerate it with the same
tooling and the slide outline above.
